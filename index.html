Heat Ahead NYC

Forecasting heating-failure risk so inspectors can prioritize NYC buildings before cold weather arrives.

Blackjack Card-Counting Simulator

A Python simulation exploring how the Hi-Lo count relates to a blackjack player’s expected return.

The Question

Investigated how accurately the Hi-Lo card-counting system predicts player advantage across True Count levels from -2 to +6 in a six-deck shoe with one deck remaining.

Implementation

Programmed a Monte Carlo simulation running 180,000 total rounds, with 20,000 rounds per count level. Solved edge-case bugs in deck normalization, dealer S17 rules, and multi-split hand logic.

Analysis

Compared simulated returns across count levels using linear regression, standard errors, and confidence intervals. Examined the estimated advantage and the uncertainty caused by a finite simulation.
